# ReFlash v0.17.74 — source publication audit

**Status: BLOCKED — NOT the complete GPL corresponding source.** Do not advertise this source-publication branch as GPL-complete, and do not merge or submit a Modrinth release based on a false source claim.

## Verified on 2026-11-18

- Original binary: ReFlash v0.17.74, Fabric Minecraft 1.21.11, Java 21, `GPL-3.0-only`. SHA-256: `e407f8e708471201f90bcbdddd0ac261ef9f745ce2c919d79389f3a70bea7922`.
- **434 JAR entries** of the original v0.17.74 archive were rebuilt from a v0.17.73 JAR and the included v0.17.74 Java helper sources and ASM patcher. Every decompressed entry matched the original byte-for-byte (ZIP-level metadata may differ).
- The new patch compilation and behavioral tests passed locally: **22 FPS tests**, **7 UI tests**, **4 dialog-label tests**. **ASM verifier: 14 classes / 383 methods** passed.
- The complete **v0.17.74 incremental patcher**, its build script, Java helper files, regression tests, and entry comparison script are published in `source-patches/v0.17.74/` on this branch.

## Why the latest GPL source is still incomplete

- A binary-to-binary JAR patch requires **v0.17.73.jar**. It is not a source-first rebuild of the base. This is *not* a substitute for the preferred source form of the full distributed work.
- The older public repository has only historical source (approximately **v0.11.4**).
- Latest JAR has **402 compiled .class entries**, of which **307 are top-level classes**: **193 ReFlash** and **114 Momenton-derived**.
- Across the historical repository and the locally available source-patch bundles, only **61 of the 193 ReFlash top-level classes** had any matching Java source file at all. **132 ReFlash top-level classes had no Java source file in those materials**. These numbers are an upper bound on availability, *not* proof that the 61 matching files are up to date.
- The original Momenton source ZIP and GPL notices are in the old repository, but the source corresponding to all modifications in the bundled engine has not been recovered or rebuilt.
- Missing legacy-to-v0.15.60 development sources and the complete changes behind intermediate binaries (including the v0.17.73-only fixes) mean no complete independent source build can be demonstrated.
