**Status: BLOCKED — NOT complete GPL corresponding source.** This branch is for source recovery; do not advertise it as GPL-complete, merge to `main`, or use it as a Modrinth source-compliance link for the v0.17.74 release yet.

- Original v0.17.74 binary: Fabric Minecraft 1.21.11, Java 21, `GPL-3.0-only`, SHA-256 `e407f8e708471201f90bcbdddd0ac261ef9f745ce2c919d79389f3a70bea7922`.

Each recompiled Java class matched its v0.17.73 compiled class **byte-for-byte**. Packaging against the exact v0.17.72 JAR reproduced **431/431 archive entries** in v0.17.73. Source diff, build script and notes are in `source-patches/v0.17.73/`.
- **ReFlash v0.17.73 → v0.17.74**: source-patch build reproduced **434/434 archive entries** of the v0.17.74 JAR, each entry identical in decompressed bytes. Latest source files, patcher, build script, tests and changelog are in `source-patches/v0.17.74/`.
- Local v0.17.74 tests passed: **22 FPS checks, 7 UI simulation checks, 4 dialog-label checks**, and **ASM verification of 14 classes / 383 methods**. Original staged v0.17.74 Java/build/test files were checked against GitHub blob hashes and matched exactly.

## Why the latest GPL source is still incomplete

- These are faithful **incremental patch-source rebuilds**, but both rely on **previous compiled ReFlash JARs**. A patch applied to an older binary is not a complete clean-source build.
- The current public `main` repository only has old source (approximately v0.11.4); its complete preferred Java source has not been reconciled with the newer binary.
- v0.17.74 JAR: **402 .class entries**, **307 top-level classes**: **193 ReFlash**, **114 Momenton-derived**.
- Across local historical repository files and available source-patch ZIPs, only **61/193** ReFlash top-level classes had a matching Java source file, leaving **132 ReFlash top-level classes with no matching Java source**. Those 61 files are not necessarily current; name matching does not establish source correspondence.
- The old repository contains original Momenton v1.0.0 GPL source and notices, but complete preferred source for all currently modified bundled engine components is not verified.
- The v0.11.4→v0.15.60 development period contains source gaps. The available source ZIPs cannot independently compile the modern mod without older binaries.

## Required publication gates

1. Recover/rebuild the preferred modifiable Java source for all current ReFlash and modified Momenton components, including at least the 132 missing ReFlash top-level classes.
2. Reconcile intermediate releases and remove the requirement for old **compiled ReFlash JARs** as a build input.
3. Document all dependencies, build/install scripts, copyright notices and GPL-3.0-only attribution.
4. Run the necessary initial check `python3 tools/audit_current_source.py path/to/current.jar src/main/java source-patches/v0.17.74/src` (it currently **fails**). A passing inventory check would still be insufficient: verify actual source correspondence.
5. Build a modern JAR from source in a clean environment and verify it structurally and in Fabric 1.21.11 with VulkanMod where possible.
6. Obtain owner approval before any public release and only then provide the complete source URL to Modrinth.

## Publication rule

This development branch and draft PR demonstrate **recovered patch sources and verified transformations**, not full GPL compliance. No unverified claim should be used to satisfy Modrinth's GPL source requirement.
